# Retail Sales EDA Project (Tauheed Ahmad)

Retail sales EDA built on the t_a project structure, using Tauheed's dataset and dashboard code.

## Project structure

```text
Tauheed_Ahmad_EDA_Project/
├── data_processing.py            # cleaning, KPIs, quality report, charts (t_a pipeline)
├── eda_practice_retail_sales.csv # source data (Tauheed's retail_sales.csv, unchanged)
├── requirements.txt
├── .gitignore
├── notebooks/
│   └── retail_sales_eda.ipynb
├── output/                       # generated by data_processing.py
│   ├── charts/
│   ├── retail_cleaned.csv
│   ├── kpi_summary.csv
│   ├── data_quality_report.csv
│   ├── outlier_report.csv
│   └── cleaning_summary.json
└── dashboard/                    # Tauheed's Streamlit dashboard (unchanged code)
    ├── app.py
    ├── pipeline.py
    └── requirements.txt
```

## Setup

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run the EDA pipeline

```bash
python data_processing.py --input eda_practice_retail_sales.csv
```

## Run the dashboard

```bash
cd dashboard
pip install -r requirements.txt
streamlit run app.py
```

The dashboard reads `retail_sales.csv` from its own folder, so copy the CSV into `dashboard/` or upload it from the sidebar.
